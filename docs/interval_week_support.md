# 间周上课功能支持说明

## 修改内容

本次修改为吉林大学课表导入功能添加了间周上课的支持，解决了某些课程因为间周上课而无法正常识别的问题。

## 支持的格式

### 原有格式（已支持）
- **连续周次**：`2-10周` → 第2, 3, 4, 5, 6, 7, 8, 9, 10周
- **单周**：`5周` → 第5周

### 新增格式（本次添加）
- **间周上课（单周）**：
  - `1-15周(单周)` → 第1, 3, 5, 7, 9, 11, 13, 15周
  - `3-13周(单)` → 第3, 5, 7, 9, 11, 13周
  - `1-15周（单周）` → 第1, 3, 5, 7, 9, 11, 13, 15周（中文括号）

- **间周上课（双周）**：
  - `2-16周(双周)` → 第2, 4, 6, 8, 10, 12, 14, 16周
  - `4-14周(双)` → 第4, 6, 8, 10, 12, 14周
  - `2-14周（双周）` → 第2, 4, 6, 8, 10, 12, 14周（中文括号）

## 修改文件

1. **`lib/widgets/simple_webview_login.dart`**：
   - 修改了JavaScript中的周次解析逻辑
   - 添加了间周上课的正则表达式匹配
   - 实现了单周/双周的分别处理逻辑

## 技术实现

### 解析逻辑
1. **优先匹配间周格式**：使用正则表达式 `/(\\d+)-(\\d+)周[\\s]*[\\(（]([单双])[周]?[\\)）]/` 匹配间周格式
2. **单周处理**：当匹配到"单"字时，只取奇数周（w % 2 === 1）
3. **双周处理**：当匹配到"双"字时，只取偶数周（w % 2 === 0）
4. **向后兼容**：如不匹配间周格式，则按原有连续周次逻辑处理

### 测试验证
- 创建了完整的单元测试（`test/week_parsing_test.js`）
- 测试了9种不同的周次格式
- 所有测试用例均通过验证

## 使用说明

更新后的版本可以正确识别和导入包含间周上课的课程，无需用户做任何额外操作：

1. 在WebView中登录吉大教务系统
2. 打开课表页面
3. 点击"下载"按钮提取课程
4. 系统会自动识别并正确处理间周上课的课程

- 不影响现有功能，完全向后兼容

- 新增间周课程的识别和处理能力
- Course模型的weeks字段完美支持间周周次列表
